# emotion-vectors-repro

Reproduction of Anthropic's emotion-vector work on Qwen/Qwen3.5-4B. The PCA and valence/arousal correspondence reproduce; the implicit retrieval test does not.

## What it does

The pipeline:

1. Generates stories expressing 171 emotion concepts, plus neutral text (`ev1_gen.py`).
2. Extracts residual activations from Qwen3.5-4B at layers 8, 14, 21, 26, and 31 (`ev2_extract.py`).
3. Runs PCA on the emotion activations at analysis layer 21 and correlates the principal components with human ratings (`ev3_analyze.py`).
4. Runs an activation-steering sweep (`ev4_steer.py`).
5. Fits LDA classifiers and runs steering diagnostics (`ev5_lda.py`, `ev6_lda_final.py`, `ev6b.py`, `ev7_test.py`, `ev8_diag.py`, `ev9_sweep.py`).

`evcommon.py` holds shared model and config helpers. `app_phone.py` is a phone-friendly companion app.

## Limitation: the implicit retrieval test failed

The implicit validation asks whether the activation representation can recover the target emotion from text that expresses it without naming it. It did not work. hit@1, hit@5, and hit@10 were all 0/12, and the mean and median ranks (50.0 and 39.0) do not show the targets ranked near the top. The chance hit@5 rate is 2.92%, and the observed rate was 0%.

What this means: the PCA structure and its correlation with valence and arousal are real signal in this setup. Retrieval of individual implicit emotions from the probe is not. Claims about the representation should be limited to the axes the PCA and correlation results support.

The steering sweep (`ev4_steer.py`, `ev9_sweep.py`) is included, but this repo does not report a successful steering result, and nothing here should be read as evidence that steering works.

## Repository layout

```
ev1_gen.py          generate emotion and neutral stories
ev2_extract.py      extract activations at layers 8, 14, 21, 26, 31
ev3_analyze.py      PCA and human-rating correlations
ev4_steer.py        activation steering sweep
ev5_lda.py          LDA classifier
ev6_lda_final.py    final LDA run
ev6b.py             LDA follow-up
ev7_test.py         test script
ev8_diag.py         steering diagnostics
ev9_sweep.py        LDA classifiers and steering diagnostics sweep
evcommon.py         shared model and config helpers
app_phone.py        phone-friendly companion app
stories.jsonl       generated stories
neutral.jsonl       neutral texts
blackmail_transcripts.jsonl   harmful-behaviour scenario from the source paper
analysis.json       all results
```

The `.npz` activation vectors are not in the repo.

## How to run

Run the numbered scripts in order, `ev1_gen.py` through `ev9_sweep.py`. Each stage reads the outputs of the previous one. `evcommon.py` is imported by the scripts and is not run directly. Results are written to `analysis.json`.

## Hardware

One NVIDIA RTX 5070 Ti with 16 GB VRAM, running under WSL2.

## Regenerating activations

The `.npz` activation vectors are excluded from the repo because they can be regenerated by running `ev1_gen.py` and `ev2_extract.py` on the same model.
